# tpeweb2-2025

## :brain: Descripción del Proyecto
Este proyecto consiste en una página web con la temática de la serie **"Peaky Blinders"**.  
La aplicación permite visualizar las temporadas y sus respectivos capítulos, además de contar con un sistema de usuarios que posibilita la administración del contenido.

El sitio fue desarrollado utilizando **PHP** y **MySQL**, con un enfoque en la manipulación de datos relacionales y en la gestión dinámica de información.

---

## :closed_lock_with_key: Sistema de Usuarios

El sistema de usuarios permite dos modos de interacción:

- **Modo visitante:**  
  Los usuarios pueden navegar por la página y visualizar las temporadas y capítulos disponibles.

- **Modo administrador (usuario registrado):**  
  Permite **agregar**, **editar** o **eliminar** tanto **temporadas** como **capítulos**.  
  El acceso se realiza mediante inicio de sesión con nombre de usuario y contraseña.

---

## :gear: Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3  
- **Backend:** PHP  
- **Base de datos:** MySQL  
- **Servidor local recomendado:** XAMPP o Laragon
